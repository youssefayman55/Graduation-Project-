# 🧠 Emotion Detection System using Machine Learning & Flask API

## 🚀 Overview
This project is an **end-to-end Machine Learning system** for emotion classification based on physiological data such as:

- ❤️ Heart Rate  
- 🎂 Age  

It includes:
- Full **Data Analysis & Model Training Pipeline**
- Comparison between multiple ML algorithms
- Best model selection (XGBoost / Ensemble models)
- Deployment using a **Flask REST API**

The system predicts emotions such as:
😡 Angry, 😨 Fear, 😊 Happy, 😐 Normal, 😢 Sad
